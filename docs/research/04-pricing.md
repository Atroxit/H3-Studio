# 04 Pricing and Rate Limits (MiniMax-H3-Image)

Slice: how MiniMax-H3-Image and MiniMax-H3-Image-Highspeed are billed (per image and per token), what an
M Plan key changes versus a pay-as-you-go key, and the documented rate limits.
API host: `https://api.minimax.io`. Models: `MiniMax-H3-Image`, `MiniMax-H3-Image-Highspeed`.

## Facts

1. Pay-as-you-go image billing is per million tokens, split three ways: MiniMax-H3-Image input text $2.30, input
   image $1.50, output image $3.80. MiniMax-H3-Image-Highspeed is $2.30, $3.00, $7.60 for the same three columns.
   - Source: https://platform.minimax.io/docs/pricing/overview.md (Image Generation table, "Model / Input Text /
     Input Image / Output Image, $ per M tokens")
   - Confidence: documented

2. Documented example totals per single image, text-to-image: H3-Image 1K $0.02179, 2K $0.02333, 4K $0.06879;
   Highspeed 1K $0.03529, 2K $0.03622, 4K $0.13001. The page calls these illustrative, not quoted rates.
   - Source: https://platform.minimax.io/docs/pricing/overview.md
   - Confidence: documented

3. Edit examples list each reference image under an "Input image (each)" column and cost more than text-to-image:
   H3-Image at 1K output is $0.02654 with one reference image and $0.03563 with three.
   - Source: https://platform.minimax.io/docs/pricing/overview.md ("Example cost per generated image")
   - Confidence: documented

4. Only successful images are charged. A failed item, including one withheld by the content safety check, carries
   only an `error` object in `data[]`, and the call still returns HTTP 200 if at least one image succeeded.
   - Source: https://platform.minimax.io/docs/api-reference/image-generation-h3-generations.md
   - Confidence: documented

5. Each response reports the meter to bill against in `usage`: `generated_images`, `total_tokens`, `input_tokens`,
   `output_tokens`, `input_tokens_details.text_tokens`, `input_tokens_details.image_tokens`,
   `output_tokens_details.image_tokens`. Apply the per-million-token prices to these numbers.
   - Source: https://platform.minimax.io/docs/api-reference/image/generation/api/h3-image-generations.json
   - Confidence: verified (OpenAPI spec: response and `image_generation.completed` schemas)

6. Prompt enhancement output is billed as input text, so two requests at the same size can cost different amounts.
   H3-Image-Context-IR used alone is $2.30 per M input tokens with an RPM limit of 200.
   - Source: https://platform.minimax.io/docs/pricing/overview.md ("actual costs may vary depending on the number of
     text input tokens ... include those generated by prompt enhancement"), https://platform.minimax.io/docs/guides/rate-limits.md
   - Confidence: documented

7. Image rate limit is IPM 1000 per model, not shared: text-to-image and image edit on the same model share that
   model's quota, and one request with `n` images counts as `n` images. RPM and TPM for these rows are shown as unset.
   - Source: https://platform.minimax.io/docs/guides/rate-limits.md (Image table and IPM note)
   - Confidence: documented

8. M Plan and pay-as-you-go keys are not interchangeable. An M Plan key draws the included quota first, then Credits,
   and never charges the account balance; a pay-as-you-go key charges the account balance. M Plan image and video use
   counts against the weekly window only, with no 5-hour window, and H3 Image is on Go, Explore and Build while
   Highspeed is only on Explore and Build.
   - Source: https://platform.minimax.io/docs/m-plan/faq.md, https://platform.minimax.io/docs/m-plan/intro.md
   - Confidence: documented (key rules from the FAQ; tier table read from the rendered intro page)

## Gaps

- No formula is published for how output image tokens derive from pixel area, so exact cost per arbitrary
  `WIDTHxHEIGHT` cannot be computed from the docs; only the example totals are given.
- Whether input text tokens are billed once per request or once per generated image when `n` is greater than 1 is
  not stated. The same question applies to input image tokens on edit requests with several references.
- No free quota is documented for the image endpoints. "Beyond free quota" wording appears only in the video pricing
  tables; legacy `image-01` is priced as a flat $0.0035 per image, but no equivalent allowance for H3 Image is stated.
- The rate limit page lists IPM per model without saying whether M Plan keys use the same IPM 1000 as pay-as-you-go
  keys. The M Plan FAQ only says RPM and TPM may be throttled and recover in about a minute.
- With RPM and TPM shown as unset for the image rows, no request-per-minute ceiling is documented for text-to-image
  or image edit. Whether a 429 body accompanies an IPM breach on these endpoints is not documented.
- The 4K column shows a limited-time 50% discount ending 2026-11-17 16:00 UTC for final images of at least
  16,600,000 pixels. Behaviour for a request that starts before and finishes after that cutoff is not stated.
- M Plan quota consumption per generated image is not quantified; the FAQ says cost depends on model, context length
  and task complexity, so a client cannot convert images to a share of the weekly allowance.
- Whether `response_format` (`url` versus `b64_json`) or streaming changes token counts, and therefore price, is
  not stated.
- No live request was attempted for this slice: billing and balance errors need an authenticated key, so the
  `base_resp` error shape for insufficient balance was not confirmed.
